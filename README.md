# LSP Alarm

Excel 파일 또는 텍스트 파일의 변화를 감시하고, 조건이 충족되면 카카오톡 메시지를 전송하는 알람 프로젝트입니다.

# 목적

근무시간에 누군가가 파라미터를 변경했는데 원복하지 않아서 미검출된 상태로 많은 양의 셀이 유츌됨.
이를 계기로 파라미터 변경시 자동으로 시간별 근무자와 값들이 기록되도록 하는 프로그램을 제작.

## 프로젝트 구성 및 동작 흐름

```text
카카오 로그인/인가 코드
        ↓
Access_token.py ── 액세스 토큰·리프레시 토큰 발급
        ↓ 수동 복사
refesh_token.py ── 만료된 액세스 토큰 갱신
        ↓ 수동 입력
┌──────────────────────────────────────┐
│ send_me.py                           │
│ 사용자가 직접 메시지를 입력해 테스트 │
├──────────────────────────────────────┤
│ ExelFile_trigger_alarm.py            │
│ Excel B2:E6 변경 감시 → 카카오 메시지 │
├──────────────────────────────────────┤
│ file_monitor_app.py                  │
│ 텍스트 숫자 추가 감시 → 임계값 비교   │
└──────────────────────────────────────┘
```
